# ✈️ Airline Passenger Satisfaction Prediction

A Machine Learning project that predicts whether an airline passenger is satisfied or dissatisfied based on flight experience and service-related features.

## 📊 Project Overview

This project uses airline passenger survey data to build and compare multiple classification models. The goal is to identify the model that best predicts customer satisfaction.

## 🔧 Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn

## 🤖 Models Implemented

* Decision Tree
* Random Forest
* K-Nearest Neighbors (KNN)
* Naive Bayes
* Support Vector Machine (SVM)

## 🏆 Results

The **Random Forest Classifier** achieved the best performance with an accuracy of **96.08%**.
